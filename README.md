# 监测工作台 V1.07 · 网页版

网页版所有代码、依赖、配置和数据都位于本文件夹，独立于桌面版 `V1.07`。

基于官方 [FastAPI Full Stack Template](https://github.com/fastapi/full-stack-fastapi-template) 改造，保留 FastAPI、SQLModel、Argon2/JWT 登录、React/TypeScript、Vite、TanStack 与 shadcn/ui 基础。原始模板快照及 MIT 许可证保留在 `upstream/template.zip`、`LICENSE`；来源提交为 `cb740b656d7a0a6c5e12c7bf8e50343ec94ee9c7`。由于本机使用 Python 3.12，已适配原模板中的 Python 3.14 语法和依赖要求。

## 直接使用

本机已经安装依赖并构建前端。双击 **start.cmd**，服务就绪后会自动打开浏览器，默认地址 **http://127.0.0.1:8007**。重复启动会复用本文件夹已运行的服务；如果端口被其他程序占用，会自动选择后续空闲端口，并显示实际地址，不会结束其他程序。

初始管理员账号和随机密码在 **data/首次登录.txt**。登录后建议点击左下角“修改密码”；该文件仅记录初始密码。管理员在“用户管理”中新建普通用户，再把账号交给项目人员。

换电脑后：
1. 安装 Python 3.12 和 Node.js 20.19+（推荐 Node.js LTS）。
2. 双击 `install.cmd`，等待依赖安装与前端构建完成。
3. 双击 `start.cmd`。首次启动的服务窗口需要保持打开，按 Ctrl+C 停止；重复启动只打开浏览器。
4. 端口冲突可运行 `powershell -ExecutionPolicy Bypass -File start.ps1 -Port 8010`。

首次安装生成独立随机密钥和密码；重复安装会保留已有配置、账号和工程数据。`start.cmd` 支持局域网访问，不会自动发布到互联网。

## 账号和工程权限

| 功能 | 项目用户 | 管理员 |
|---|---|---|
| 登录进入我的项目 | 支持 | 支持 |
| 新建工程 | 需数据录入权限，自动归属本人 | 自动归属本人 |
| 数据录入、数据库数据、数据库图表、智能分析、报告生成 | 自己创建或加入的工程，且具有对应功能权限 | 可管理全部工程 |
| 添加/移除工程成员 | 仅自己创建的工程 | 可管理全部工程 |
| 删除工程 | 仅自己创建的工程，不依赖数据录入权限 | 可删除全部工程 |
| 设置账号默认权限、工程成员权限 | 不开放 | 开放 |
| 全部项目 | 不开放 | 开放 |
| 新建账号、修改角色、停用账号、重设密码 | 不开放 | 开放 |

一个工程可关联多个账号，一个账号也可以参与多个工程。创建人或管理员进入工程后，点击右上角 **工程成员**，填写已有账号的登录邮箱并添加。新账号先由管理员在“用户管理”中创建。成员登录后在“我的项目”中看到共享工程，扫码也能进入对应测项；各账号的图表设置独立保存。移除成员后，后续工程请求立即被拒绝，管理员始终保留全部工程权限。

管理员添加或编辑账号时可独立勾选 **数据录入、数据库数据、数据库图表、智能分析、报告生成**，也可使用“查看与分析”“数据编辑”“仅报告”快捷组合。工程内只显示获准的入口和操作按钮；接口同样检查权限。新建用户窗口默认“查看与分析”。原“数据库”授权兼容为数据与图表查看，所有原始数据修改统一需要“数据录入”；管理员可重新勾选调整。

默认权限适用于该账号创建及加入的工程；管理员可在 **工程成员 → 设置权限** 中对当前工程单独配置，或恢复使用账号默认权限。工程创建人也遵守功能限制，不能自行提升权限。“数据库数据”允许选择日期，“数据库图表”允许保存个人图表配置、扫码查看；二者独立授权，均不包含原始数据编辑。

每次请求均从 JWT 识别用户，再从数据库检查账号状态、管理员角色、工程 owner_id 及成员关系。创建和修改工程的输入不接受 owner_id，普通用户不能通过修改 URL 或调用隐藏接口访问未加入的工程。工程数据、文档、分析和报告共用同一个服务端权限依赖。成员管理和删除工程额外校验创建人或管理员身份。已有工程归属保持不变，启动时自动创建成员表。

停用账号立即阻断其已有令牌；修改密码后旧令牌失效。页面刷新后无需再次登录，同一个浏览器标签关闭后需重新登录；退出会清除当前会话。账号由管理员分配，没有公开注册入口。

## 使用流程

每个测项图表现有专属二维码，扫码登录后可查看图表并调整配置。`start.cmd` 默认支持同一局域网访问；本机防火墙需右键 `enable-lan.cmd` 以管理员身份运行一次。公网部署后可配置 `PUBLIC_BASE_URL` 切换二维码地址。详见 [二维码与手机访问](docs/chart-qr.md)。

1. 登录 → 我的项目 → 新建工程。
2. 进入“数据录入”，先从六个图标入口选择监测类型，再进入该类型的测项和单期表格。选择监测日期与常规/加密批次，在参数区配置轴力、水位、倾斜或孔号参数，填写原始读数或导入 Excel / UTF-8 CSV，核对预览后保存；仅保存当前期次，其他期次保留。“更换监测类型”可返回选择页，未保存修改会先提示。详细流程见 [与桌面一致的数据录入](docs/desktop-entry.md)。
3. 也可用右上角“导入工程”导入桌面 `.proj`。这会替换当前网页工程数据，需要确认；工程归属始终保持当前网页工程的归属。原始数据、计算参数和阈值配置参与导入，桌面模板布局及美化数据不参与网页分析。
4. “智能分析”可选择测项、点位、日期，执行确定性计算，查看累计变化趋势和明细；不同单位分图显示，曲线可勾选。
5. “智能分析”中的“数字孪生 3D 沙盘”支持“上传 DWG 自动生成”。后端读取 DWG 模型空间的结构图层，转换为标准化场景 JSON（图层、几何对象、坐标范围和 3D 高度规则），先在网页预览，再从当前工程数据库选择并放置测点；DWG 中的文字图例不会自动变成测点。
6. “项目资料”上传 TXT、MD、PDF、DOCX、XLSX，建立当前工程独立资料库。配置模型后使用 AI 问答；显示接口返回的思考内容、结论、引用依据和待复核提示。
7. “报告生成”先预览，再导出当前预览范围的 Excel（统计摘要、分析明细、待复核）。更改右侧筛选后需要重新预览，导出仍对应上次预览范围。
8. “导出工程”将当前数据下载为 `.proj`，用于备份或在桌面版继续处理；桌面和网页的数据不会自动同步。
9. 创建人和管理员可在项目列表或工程顶部点击“删除工程”。确认框显示工程名及删除影响，选择“确认删除”后执行；普通成员没有删除入口，后台也拒绝删除请求。

## 数据口径和本轮边界

“数据库数据”和“数据库图表”是两个独立入口：前者支持原始数据 / 日报计算数据、搜索排序分页，后者展示各测项图表。图表默认显示累计值绝对值最大的前 10 点，也可显示所有点或勾选自选点；模式、点位、图表形式、日期按账号和工程保存在服务器。详细规则及 GitHub 图表选型见 [数据库与日报图表说明](docs/database-charts.md)。

- 复用桌面 V1.07 的监测计算与资料检索源码快照，位于 `backend/vendor/monitoring_daily`；不依赖桌面安装目录。
- 水准与水平坐标以 m 录入；轴力按参数库和频率（Hz）计算 kN；倾斜按关联水准点累计沉降差与距离（m）计算 ‰；水位由参数库管口高程减去水位读数（m）；测斜按孔号和单期深度/测值（mm）录入，数据库仍按日期列存储。直接复用桌面参数校验及计算服务。无参数的旧导入结果保留，配置参数后使用桌面联动逻辑。
- 分析只使用原始数据；缺测不会补零。未配置阈值时明确显示未知，不能作为安全判定。现阶段阈值从导入的桌面工程配置读取。
- 单测项最多 20000 行，单次上传 20 MB；录入表支持每页 100 行、筛选和 Excel 多单元格粘贴。Excel 使用与桌面一致的工作表名称/字段，可下载模板；导入先预览，不自动保存。分析明细/趋势最多 1000 条，AI 明细最多 60 条；超限会给出截断提示。综合分析的各测项统计仍覆盖全区间，导出保留截断和缺失提示。
- PDF 使用文本层解析。扫描件需先在桌面 Docling OCR 中转换为可检索文本，再上传；网页版尚未安装 Docling OCR。
- 报告为标准 Excel 报告。本轮未移植桌面自定义 Excel 模板设计器、数据美化编辑器、仪器文件批量导入及扫描件 OCR 服务。
- AI 模型是可选服务；没有配置时可以正常使用项目、数据、统计和报告，AI 问答会明确提示尚未配置，不伪造答案。

## 配置云端或本地模型

编辑本目录 `.env`，然后重启服务：

```dotenv
AI_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
AI_MODEL=控制台示例中的完整模型ID或推理接入点ID
AI_API_KEY=你的密钥
AI_TIMEOUT=90
```

本地 OpenAI 兼容模型也支持。例如 Ollama 使用 `http://127.0.0.1:11434/v1`，填写本地已安装的模型名称，`AI_API_KEY` 可以留空。这里的 127.0.0.1 指运行网页后端的电脑。

模型地址、名称和密钥由服务器配置，用户上传的文档或问题不能改写服务地址。密钥不会返回浏览器；问答时选中的资料片段和监测摘要会发送到配置的服务。当前没有代为填入或验证真实云端 Key。

## 数据保存与部署

默认数据库为 `data/monitoring.db`（SQLite），项目资料位于 `data/projects/<工程UUID>/`。备份时停止服务，复制整个 `data` 目录及 `.env`；数据库和文档须一起备份。删除工程后资料目录暂留用于人工备份恢复，普通接口不再允许访问。

可通过 `DATABASE_URL=postgresql+psycopg://账号:密码@主机:5432/数据库` 使用 PostgreSQL。启动自动创建初始表；本轮已验证 SQLite，未连接实际 PostgreSQL 验收。生产升级现有表结构前需要新增迁移脚本，不能把 create_all 当作升级迁移。

本轮交付是本机可运行版本；未部署公网。供多人联网使用时，还需配置服务器、HTTPS、反向代理上传限制、备份和访问地址。原模板部署文件已归档至 `upstream/support`，不能直接拿来部署本适配版本。

`.env`、首次登录文件和 `data` 含有私密信息，已加入 Git 忽略规则。不要把它们发到公开仓库。

## 开发与验证

```powershell
# 后端完整测试（在 V1.07-Web 下）
.\.venv\Scripts\python.exe -m pytest

# 前端构建
cd frontend
npm run build

# 浏览器验收：先启动隔离的验收服务（见 docs/verification.md）
npm test
```

开发时后端启动在 8007 端口，前端 `npm run dev` 使用 5173 并代理 API。修改前端后，普通启动前需要重新构建；双击 `install.cmd` 也会重新构建且保留数据。

- `backend/app/api/routes/accounts.py`：登录和管理员账号管理。
- `backend/app/api/routes/projects.py`：工程归属、CRUD 与乐观锁。
- `backend/app/api/routes/workspace.py`：数据、资料、分析、报告。
- `backend/app/monitoring.py`：桌面计算核心的网页适配。
- `frontend/src/pages`：登录、我的项目、工程工作空间和管理员页面。
- `docs/superpowers`：需求与实现计划。
- `upstream`：上游模板原始资料，仅供溯源参考，不参与运行。
