# 测项图表二维码

数据库 → 图表：每个测项标题旁显示二维码。点击可以放大、复制链接、下载 SVG。扫码后进入单独的测项图表页，可以调整日期、图表形式及点位选择。配置继续按账号、工程、测项保存。

二维码只携带工程 ID 和测项定位地址，不包含账号密码或登录令牌。未登录时进入登录页，登录成功自动返回原图表。只有工程创建人、成员和管理员可获取图表、读取数据、修改设置；二维码不自动授予权限。

若出现“工程不存在或没有访问权限”，先核对页面显示的当前登录账号。由创建人或管理员在工程右上角“工程成员”中添加该账号邮箱，再重新加载；也可以点击“切换账号并返回此图表”，使用已授权账号登录。工程已删除时应重新获取现有工程的二维码。成员被移除后，后续工程请求立即失去权限。

## 局域网使用

1. 双击 `start.cmd`，现在默认启用局域网模式。启动窗口输出电脑地址和 Phone / LAN 地址。保持服务窗口打开。
2. 手机连接同一 Wi-Fi / 局域网，扫描图表二维码，登录对应账号。
3. 本机实测局域网地址为 `192.168.1.4`，默认端口 8007；换网络或重新分配 IP 后应重新获取二维码。
4. 如旧服务只监听 127.0.0.1，二维码区域会提示重新启动。重复启动局域网模式不会误用仅本机可访问的服务；原端口被占用时会选择后续端口，二维码使用实际端口。

### 本机已发现的 Windows 防火墙限制

当前 WLAN 为 Public，存在阻止 `D:\miniconda3\python.exe` 的公共网络 TCP/UDP 入站规则。普通会话没有管理员权限，不能直接更改。

在文件资源管理器中右键本目录的 **enable-lan.cmd → 以管理员身份运行**。它只执行以下操作：

- 为当前 Python 运行时开放本地子网到 TCP 8007 的连接；不开放整个网络、其他程序或其他端口。
- Windows 的明确 Block 优先于 Allow，因此把已有针对该 Python 的 TCP 全端口阻止规则缩小为除 8007 外的其他端口；UDP 阻止规则保持不变。
- 修改前将对应规则原始信息保存到 `data/lan-firewall-backup-8007.json`，便于检查。
- 重复运行复用本软件专属规则。非管理员运行时不做更改。

如果服务使用了其他端口，可在管理员 PowerShell 中运行 `./enable-lan.ps1 -Port 实际端口`。脚本不会修改 Wi-Fi 的网络类别，也不会关闭 Windows 防火墙。

仅需要本机访问时，可运行 `powershell -ExecutionPolicy Bypass -File start.ps1`（不带 `-Lan`）。

## 后续公网部署

将网站部署到可访问的 HTTPS 域名后，在服务器 `.env` 增加：

```dotenv
PUBLIC_BASE_URL=https://monitor.example.com
```

换成实际域名并重启服务，二维码优先使用该地址。此配置只改变二维码地址，不会自动购买域名、部署服务器或开放路由器端口。地址必须为网站根地址，不含账号、路径、查询参数。旧的局域网二维码不会自动变成公网二维码，需要重新下载或打印。

## 验证与实现

- 新增二维码组件采用 [qrcode.react](https://github.com/zpao/qrcode.react)，本地生成 SVG，不上传工程数据到第三方二维码网站。
- 后端 `GET /projects/{id}/chart-link` 使用 ProjectDep 创建人/成员/管理员校验，并校验测项存在。
- 扫码入口 `/charts/{id}?measurement=...` 使用登录路由守卫；修复原页面渲染阶段重定向导致未登录直接进入工程页卡住的问题。
- 浏览器验收实际解码小码及大码，验证下载 SVG、中文/特殊字符测项、新会话通过局域网 IP 登录并返回、手机宽度修改及保存设置、恶意外部返回地址被拒绝。
- 同一台电脑通过局域网 IP 的浏览器测试不等同于物理手机通过防火墙的验证；真实手机访问需完成上述管理员步骤。
