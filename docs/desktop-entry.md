# 网页与桌面 V1.07 的录入对齐

本轮按用户要求替换网页原有“所有类型共用表格、手填计算结果”的方式，沿用桌面的参数定义和计算服务，桌面源码不修改。

## 各类型操作

进入工程的“数据录入”后，首先显示“选择单期监测类型”，按桌面顺序提供水准、倾斜、水平位移、支撑轴力、水位、深层水平位移六个图标入口。选择后才加载对应录入表；即使工程已有数据，也不会直接跳入某个测项。

进入后“当前测项”只列出本类型的测项，旁边提供“新建测项”按钮。点击按钮后才弹出名称窗口，填写测项名称/孔号或选择关联水准测项，确认后进入对应表格；取消弹窗保留当前草稿，确认切换时仍检查未保存内容。水位和水平位移直接打开对应表。右上角“更换监测类型”返回入口，有未保存草稿时先确认，取消切换保留草稿。倾斜尚无可关联水准数据时，提供“去录入水准数据”入口。

测项和日期设置使用浅蓝底，轴力、水位、倾斜、孔号参数集中在浅金色设置区；数据操作位于表格上方，保存按钮采用深色强调。可编辑单元格有白底和边框，自动生成单元格为灰底。手机端类型入口为两列，设置和按钮自动换行。

| 监测类型 | 网页录入方式 |
| --- | --- |
| 水准 | 选择建筑物、地表、管线、桩顶等测项或自定义名称；按期填写点号、测量值（m）、备注；可复制已有点号 |
| 水平位移 | 按期录入点号、X/Y 坐标（m）、备注；可复制已有点号 |
| 水位 | 水位参数配置点位、管口高程（m）；录入页自动加载点位，填写水位读数（m）及备注 |
| 支撑轴力 | 按支撑测项配置点号、编号和传感器参数；新增点位加载全部编号，填写频率（Hz），轴力自动计算；同点号合并显示 |
| 倾斜 | 关联一个已录入水准测项；从该测项选择两个点号及距离（m）；累计沉降差生成倾斜度（‰），结果只读 |
| 深层水平位移 | 按孔号配置起始位置、步长和总深度；录入当前期“深度、测值”，服务端转存日期列，保留其他期次 |

钢筋计以同点号的有效频率计算平均应力，缺失频率不补零，其他传感器使用 C × K × (f² − f0²)。复用 `services/axial_force.py`、`services/tilt.py`、`services/water_level.py` 和 ProjectService；参数及单位与桌面一致。轴力、倾斜计算文件已核对与桌面源码哈希一致。

## 期次、参数与保存

“监测日期”和“观测批次”区分常规与 `YYYY-MM-DD（加密）` 数据。已有期次可从下拉框载入；切换前有未保存修改时提示。录入表编辑、增删、粘贴、导入均只修改草稿，点击“保存数据”后写入当前期次，并检查工程 revision 防止覆盖其他人的修改。

参数窗口点击“保存参数”才持久化。轴力参数修改重算已有轴力；水位参数修改更新已有管口高程；水准修改（包括数据库当日编辑）重算已配置的倾斜关联。旧工程中没有参数的独立计算结果保留，防止配置前丢失数据；配置对应参数后采用桌面联动规则。倾斜数据不能在数据库中直接覆盖。

测斜生成深度按步长递增至总深度，与桌面当前实现一致；起始位置作为孔号配置保留。改变步长后重新生成录入行，匹配深度的已有读数保留；历史数据库深度不会因修改配置被自动清除。清空某期只清除该期列。

## Excel 导入

### 直接复制粘贴

- 已有录入行：从 Excel 等表格复制单列测值、整行或多行多列，点击目标起始单元格后按 Ctrl+V，向下和向右填入。空白单元格、空白行及带引号的换行备注保留位置，不压缩缺测行。
- 空表或希望明确位置：点击“批量粘贴”，选择起始行和起始列，把数据粘贴到文本框，点击“应用粘贴”。只复制测值时选择测值列；整行无表头数据按表格顺序复制，也可以带与表格一致的表头按列名对应。
- 水准、水平位移、深层水平位移在允许范围内自动补行，合计最多 20000 行。轴力和水位先配置参数、加载点位，再按当前行顺序粘贴读数；超出已有参数行数时整批拒绝，不会静默丢掉多余行。
- 序号、监测日期和计算列由系统维护。完整行含轴力/水位的点号、编号时检查是否与目标行一致，避免把测值贴到另一点位。存在筛选时先清除筛选，再批量粘贴，防止修改隐藏行。
- 参数表也可批量粘贴并校验下拉选项。粘贴只更新录入草稿，核对后仍需点击“保存数据”或“保存参数”；取消批量粘贴不会改动表格。

### 文件导入

可下载当前类型模板。复用桌面 ExcelImporter：水准“单期水准数据”、水位“单期水位数据”、水平位移“单期水平位移数据”、轴力“单期轴力数据”、测斜“ZQT-1”。支持 `.xlsx` / `.xlsm` 及 UTF-8 CSV；倾斜通过水准数据计算，无直接导入按钮。导入先显示行数和表格预览，确认后替换当前录入草稿，再点击保存。导入日期统一使用当前选择期次。

### 多行表格滚动

单期录入表按当前分页行数自然展开，纵向滚动由主页面统一处理；参数表、导入预览及“编辑当日数据”的表格由所在弹窗统一纵向滚动。弹窗打开期间暂停背景页面滚动，关闭后恢复。宽表保留横向滚动，表头吸顶；键盘聚焦右侧输入列时自动显示该列。原有单期每页 100 行、当日编辑每页 50 行及草稿保存规则不变。

## 工程删除

项目列表及工程顶部提供删除按钮，创建人和管理员可用，普通成员隐藏。确认框明确工程名称、全体成员将失去访问及备份提醒；取消不删除。接口单独检查身份与 revision，创建人没有业务功能权限时仍可删除自己创建的工程。删除数据库工程记录和关联授权后，资料文件沿用既有备份保留策略，无法再由网页访问。

## 实现位置

- `backend/app/entry.py`：桌面单期数据/参数服务适配，内存预览与存储转换。
- `backend/app/api/routes/entry.py`：按期读写、计算预览、参数写入、Excel 模板和导入。
- `frontend/src/pages/DataEntry.tsx`：类型、期次、原始数据与保存流程。
- `frontend/src/components/EntryParameters.tsx`、`EntryGrid.tsx`：参数窗口、只读计算列、点号合并、分页及多格粘贴。
- `frontend/src/components/DeleteProject.tsx`：共用删除确认框。
