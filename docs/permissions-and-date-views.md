# 权限与按期数据库显示（2026-10-04）

## 权限边界

先检查登录及账号启用状态，再检查工程归属/成员关系，最后检查功能权限。系统管理员拥有全部权限，普通创建人不因 owner_id 绕过管理员的功能设置。

| 权限 | 页面及服务端操作 |
| --- | --- |
| data_entry | 数据录入；新建工程、完整测项保存及所选日期原始数据编辑 |
| database_data | 数据库数据；按日期查看原始数据与日报计算表格 |
| database_charts | 数据库图表；查看图表、扫码及个人图表设置 |
| analysis | 确定性计算、AI 问答、查看项目资料 |
| reports | 报告预览、导出 |

上述五项独立勾选、独立显示为工程顶层入口，未获授权的页面和操作按钮不显示。工程元信息修改、原始工程导入、文档写入、完整原始数据读取及导出工程需要 data_entry。数据库表格只读账号可以选择日期，不能编辑原始数据；同时具有 data_entry 和 database_data 才在表格页显示“编辑当日数据”。工程删除独立检查创建人或管理员身份，不要求 data_entry，并保留 revision 冲突检查；成员权限赋值只允许管理员。

`GET /database` 仅返回当日表格，`GET /charts` 不返回原始读数或日报表格字段。`PUT /database-date` 仅修改日期，不授予图表配置权限；图表设置由 `PUT /chart-settings` 独立授权。报告/分析页使用仅含测项、日期、点位的目录接口。扫码页先检查 database_charts，未授权账号不会加载图表。

旧记录的 database 读取为 database_data + database_charts；database_edit 读取为 database_data，不自动扩大为完整数据录入权限。已有 data_entry 保留。新增、编辑权限只接受新五项名称，管理员保存时写入新格式；工程数据及个人偏好不重置。窗口重新获得焦点或刷新时重新读取工程权限，服务端每次请求检查。

账号默认权限和工程权限覆盖分别存储于新表，无需给原账号、工程表添加字段。创建账号、添加成员和权限赋值使用同一事务；每次请求重新读取权限，旧 JWT 不携带过期授权。

## 日期与编辑

沿用每账号、工程、测项的图表日期偏好。数据库增加日期控件，原始行与计算行由服务端按该日期生成，切换日期保留原有历史基准。测斜原始表把宽表投影为深度和当日读数列；编辑时只合并当日读数，拒绝写入其他日期。写入校验数值及工程 revision，避免并发覆盖。

## 测斜图表

横轴累计位移、纵轴深度向下。日报模式显示所选期，历史模式按日期生成多条深度剖面线，图例显示期次日期。选点格式明确位移与深度，缺测断线，控制值绘于累计位移轴。

## 复查重点

账号和单工程权限覆盖、普通用户自行提升权限、删成员再加成员、旧登录令牌的权限撤销、日期筛选、历史基准、跨日期编辑保护、版本冲突，以及测斜历史轴向、缺测和提示坐标均由测试覆盖。浏览器验收使用独立 8017 服务与验收库，不修改真实工程权限。
