# 工程成员（2026-09-27）

本次需求将单账号归属扩展为一个工程关联多个账号，取代早期版本的仅创建人可访问规则。工程仍有唯一创建人，成员关系不转移归属。

## 操作

1. 管理员在“用户管理”创建并启用账号。
2. 创建人或管理员进入工程，点击“工程成员”。
3. 填写账号登录邮箱，点击“添加成员”。可依次添加多个账号。
4. 成员登录后在“我的项目”看到该工程，具有“数据库图表”权限时也可扫码进入测项图表。
5. 点击成员旁“移除”并确认，收回后续请求的访问权限。已下载的文件或浏览器已显示的数据不远程删除。

成员按管理员授予的功能权限使用工程；未授权页面不显示，直接调用接口也拒绝。创建人也遵守功能限制。按最新要求，删除工程单独检查创建人或管理员身份，不依赖数据录入权限；两类账号可在项目列表或工程页删除，必须通过确认框，普通成员不能删除。创建人和管理员可添加、移除成员，只有管理员能设置权限；管理员具有全部工程权限。图表偏好仍按账号独立存储。

## 功能权限（2026-10-04）

管理员在“用户管理”的添加/编辑账号窗口设置默认权限，独立选择 **数据录入、数据库数据、数据库图表、智能分析、报告生成**。工程页面只显示勾选的入口，其余入口隐藏。快捷组合：查看与分析（数据库数据、数据库图表、智能分析）；数据编辑（数据录入、数据库数据）；仅报告（报告生成）。图表与数据权限互不包含。

所有原始数据修改统一要求“数据录入”权限；只勾选“数据库数据”时可以按日期查看但不能编辑，只勾选“数据库图表”时可以查看及保存个人图表配置。创建工程也需要账号默认“数据录入”权限。

默认权限对未单独设置的工程即时生效。管理员在“工程成员”里添加成员时可以选择本工程权限，也可点击已有成员（包括创建人）的“设置权限”调整；勾选“使用账号默认权限”取消本工程覆盖。账号可在不同工程使用不同权限。

移除成员会收回工程访问，但管理员设置的工程权限仍保留，防止创建人通过移除再添加绕过限制。管理员需要更改时重新设置即可。已有账号缺省保持旧版全部功能；新用户窗口默认查看与分析。权限保存在新增的 AccountPermission、ProjectPermission 表，启动时自动创建，不重写既有工程数据。

## 实现

- `ProjectMember` 使用工程 ID 与账号 ID 复合主键，外键级联删除；启动时创建新表，旧工程及 owner_id 不变。
- 列表按创建人或成员关系查询；所有工程子资源统一通过服务端 ProjectDep 授权。
- 成员增删另行检查管理权限。不对普通创建人开放全站用户列表，使用准确邮箱添加已有启用账号。
- 重复添加幂等；创建人不可移除。成员关系修改不增加数据 revision，避免干扰未保存的数据草稿。
- 未指定任何真实成员授权，因此不会自动将已有账号加入工程。

## 验证

后端新增测试涵盖加入/移除、跨工程隔离、停用账号、管理员和创建人的管理权限、成员不能删除工程、重复添加，以及图表个人设置隔离。浏览器验收覆盖添加成员、共享工程列表、扫码图表配置保存、手机尺寸布局、移除后访问拒绝。验收使用隔离数据库及 8017 端口，不修改真实工程或账号。
