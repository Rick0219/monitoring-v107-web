# 数据库数据布局与统一滚动

目标：仅调整数据库数据前端展示，取消固定高度和内部纵向滚动，默认 30 行，可选 10/20/30/40/50/全部，保留筛选、排序、日期和编辑行为。

实现：数据页筛选区合并测项、日期、内容和搜索；仅本页压缩工程标题与导航间距。原生表格随页展开，thead 单元格 sticky 位于固定顶栏下方。宽表使用不产生滚动上下文的横向 clip 视口和独立原生横向滚动控件，横向偏移整个表格；纵向滚轮/PageDown 不拦截，表头和正文始终同列对齐。
