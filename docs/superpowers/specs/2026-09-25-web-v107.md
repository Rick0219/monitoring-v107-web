# V1.07 网页端设计

用户已授权：独立文件夹，官方 FastAPI 全栈模板，两种角色，登录进入我的项目，用户创建自己的工程，工程内数据录入、智能分析、报告；管理员额外拥有用户管理和全部项目。

## 实现范围
- FastAPI + SQLModel，模板 Argon2 密码哈希与 JWT 登录；React + TypeScript + Vite + shadcn/ui。
- 本机默认 SQLite，DATABASE_URL 可配置 PostgreSQL。所有资料、数据、依赖、脚本位于 V1.07-Web。
- 工程 owner_id 只能来自登录账号；管理员跨工程查看、普通用户严格隔离。工程子资源统一经过服务端鉴权。
- 复用桌面 V1.07 的 domain/services/analysis 快照，按请求构造内存工程服务；数据持久化 SQL JSON，版本号防止覆盖并发修改。
- 工程新增、编辑、删除，桌面 .proj 导入/导出；六类监测数据表格录入、CSV 导入导出、校验。
- 确定性统计/趋势图，项目资料上传检索，真实 OpenAI-compatible AI 问答，模型由服务器环境配置（可接本地服务）；没有模型时明确提示配置需求。
- 日报范围预览、XLSX 导出。此轮不移植桌面复杂的 Excel 模板编辑器和数据美化编辑器。
- 管理员创建/停用账号、重设密码；普通用户不提供公开注册，账号由管理员分配。
- 首次启动随机生成密钥和管理员临时密码，支持首次登录后修改密码，不硬编码公用密码。

## 验收
两个普通用户互不可读写工程、资料、分析、报告；伪造 owner_id/角色无效；停用账号已有令牌不可使用；管理员可管理全部工程。完成完整后端测试、前端构建和浏览器真实流程验证。
