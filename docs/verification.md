# 验证记录与复现方法

测试数据与实际工程分离。后端 pytest 使用独立临时数据库；浏览器测试使用 data/acceptance.db 和 data/acceptance-projects，不会读写桌面工程。

## 后端
在 V1.07-Web 运行：
```powershell
.\.venv\Scripts\python.exe -m pytest
```

覆盖登录、管理员权限、伪造 owner_id、跨工程所有子资源的读取/写入、账号停用、改密后旧令牌失效、原始数据保存、并发版本冲突、工程导入验证、统计值、标准 Excel、公式注入、资料隔离、问答真实 HTTP 协议、报告筛选，以及水位/轴力/倾斜的网页录入保真。

AI 测试使用本机临时 HTTP 模型服务返回已知响应，确认真实请求携带当前工程数据；没有调用用户的云端账号或消耗其模型额度。

## 浏览器
在根目录的 PowerShell 终端：
```powershell
$env:DATABASE_URL = 'sqlite:///' + (Join-Path $PWD 'data/acceptance.db').Replace('\','/')
$env:STORAGE_DIR = Join-Path $PWD 'data/acceptance-projects'
cd backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8017
```

另开终端进入 frontend：
```powershell
$env:WEB_TEST_URL='http://127.0.0.1:8017'
npm test
```

测试读取本机 .env 中初始管理员凭据，只用于隔离测试数据库。不要将 WEB_TEST_URL 指向真实生产服务。测试会创建带时间标识的验收用户和工程。

流程：管理员登录创建普通用户 → 普通用户菜单隔离 → 新建工程 → 录入水准观测 → 修改工程信息不丢失未保存行 → 离开页面提示 → 计算 -10 mm 累计变化 → 报告预览与下载 → 管理员查看全部项目 → 桌面及390px窄屏截图。
截图位于 docs/screenshots。
